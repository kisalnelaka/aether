Build an API

I'm going to show you how to build a simple CRUD API. I assume you know how to write PHP. The whole app is under 200 lines.

Note: You need PHP 8.3+. Nothing else.
1

Project Setup

Clone the framework and make your folders. Stop using package managers for everything.

git clone https://github.com/kisalnelaka/aether.git taskapi
cd taskapi
mkdir -p app/Controllers app/Middleware app/Services
2

Configuration

Edit config/aether.php to register your scan paths:

return [
    'name' => 'Task API',
    'debug' => true,
    'controllers' => [
        'App\\Controllers' => __DIR__ . '/../app/Controllers',
    ],
    'services' => [
        'App\\Services' => __DIR__ . '/../app/Services',
    ],
];
3

Create the Data Service

Create app/Services/TaskService.php. We're keeping it in memory. I don't want to explain how to install a database.

#[Persistent]
final class TaskService
{
    private array $tasks = [];
    private int $nextId = 1;

    public function findAll(): array
    {
        return array_values($this->tasks);
    }

    public function create(string $title): array
    {
        $task = [
            'id' => $this->nextId++,
            'title' => $title,
            'completed' => false,
        ];
        $this->tasks[$task['id']] = $task;
        return $task;
    }
}
4

Create Middleware

Create app/Middleware/JsonMiddleware.php that adds timing and content-type headers:

final class JsonMiddleware implements MiddlewareInterface
{
    public function handle(Request $request, callable $next): Response
    {
        $start = hrtime(true);
        $response = $next($request);
        $ms = (hrtime(true) - $start) / 1_000_000;

        return $response
            ->withHeader('Content-Type', 'application/json')
            ->withHeader('X-Response-Time', round($ms, 3) . 'ms');
    }
}
5

Create the Controller

Create app/Controllers/TaskController.php with full CRUD:

#[Controller(prefix: '/api/tasks')]
final class TaskController
{
    public function __construct(
        private TaskService $tasks,
    ) {}

    #[Get(path: '/')]
    public function index(Request $r): Response
    {
        return Response::json(['data' => $this->tasks->findAll()]);
    }

    #[Post(path: '/')]
    public function create(Request $r): Response
    {
        $body = $r->json();
        $task = $this->tasks->create($body['title'] ?? '');
        return Response::json(['data' => $task], 201);
    }

    #[Delete(path: '/{id}')]
    public function destroy(Request $r): Response
    {
        $id = (int)$r->getRouteParam('id');
        $this->tasks->delete($id);
        return Response::json(['message' => 'Deleted']);
    }
}
6

Create the Entry Point

Create public/index.php:

require_once __DIR__ . '/../aether.php';

$app = Application::create(AETHER_ROOT);
$app->middleware(JsonMiddleware::class);

$app->get('/api/tasks', 'TaskController@index');
$app->post('/api/tasks', 'TaskController@create');
$app->delete('/api/tasks/{id}', 'TaskController@destroy');

$app->run();
7

Run and Test

php -S localhost:8080 public/index.php
Try it

Open a new terminal and run these commands:

# List tasks
curl http://localhost:8080/api/tasks

# Create a task
curl -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Learn AETHER"}'

# Delete a task
curl -X DELETE http://localhost:8080/api/tasks/1
8

AOT Compilation

If you put this in production without compiling, it's your own fault when it's slow.

php bin/aether aot:compile

This generates three files in cache/:

  • compiled_routes.php -- serialized Radix Tree
  • compiled_hydrators.php -- static DI factory functions
  • compiled_classmap.php -- optimized autoloader map

The Kernel loads these files automatically instead of scanning your attributes with Reflection.

9

Route Groups

Organize versioned APIs with groups:

$app->group('/api/v2', function ($r) {
    $r->get('/tasks', 'TaskController@index');
    $r->post('/tasks', 'TaskController@create');
}, middleware: ['AuthMiddleware']);
